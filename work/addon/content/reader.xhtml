问题列表

优先复用有效草稿，科研缩写和化学式允许保留。只有缺失或不合格的完整段落才补译；相同内容的失败不会反复请求。排版失败显示中文诊断图，未通过检查不能应用。自动翻译每个完整段落最多尝试两次，重开窗口仍保留次数。主动重新尝试可能产生 API 费用；排版问题不会通过重复翻译解决。有效译文会保存；已有的正式译版不会被失败结果覆盖。
